## 四项宿主核对

1. 原问题要求的信息是否齐全，例如具体 URL、流程步骤或数值。
2. 对象、版本、时间和适用范围是否一致，改写不能丢掉原问约束。
3. 来源状态、有效期和冲突是否允许作为当前依据；来源不清或冲突未解决时明确待确认。
4. 每个关键结论是否有对应原文；部分有支持时只回答有依据的部分，并说明缺口。

充分、部分支持、不足和冲突需确认是宿主核对后的语义结论。
本期检索平台仍只能返回 not_assessed，不将这个字段包装成已实现的独立语义判定器。
工具说明不能保证所有宿主强制执行；真实语义效果需案例与人工审查验证。
