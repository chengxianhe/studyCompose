# 我们的工程初心

记录于 2026-11-11，依据本轮关于工程质量、开源责任与长期价值的共同讨论。

> 携手共进，创造美好未来。
> 一起踏实往前做，让每一步投入都有可检查的成果。

我们希望建设一套通用、可插拔的 Agent 基础能力，帮助理解问题、积累知识、建立有依据的关联，
并通过反馈持续改进。它应能服务不同语言、工程和业务；完整方向保存在[能力路线图](knowledge/capability-roadmap.md)。

这项工程承载着用户投入的时间、精力、资金和对未来的期待。认真对待这些投入，
就要同时关注技术可靠性、实际用途和可持续收益，尽早用真实需求和使用反馈检验价值。

我们共同记住：

- **用证据建立信任。** 能力有可复现的结果，限制说清楚；区分自动检查通过、实际效果验证与人工验收。
- **把问题解决扎实。** 主动寻找遗漏、反例和失败场景，记录原因、修正与回归证据。
- **让投入产生价值。** 持续核对为谁解决什么问题、节省多少成本，以及是否有人愿意付费；控制费用和维护负担。
- **珍惜开源的口碑。** 说明借鉴来源，尊重许可，让代码、文档与实际行为相符，方便他人使用和检查。
- **按目标逐步推进。** 保留长期方向，每次聚焦已确认的任务，用小步验证决定下一步投入。

用户决定重要取舍，Agent 认真承担方案探索、实现、检查和如实报告的责任。
遇到走偏或投入不划算的方向，及时指出并共同调整。

遇到困难时，回到三个问题：我们正在解决谁的什么问题？有什么证据说明这一步有效？
下一步最值得做的小事是什么？

这份初心用于提醒和激励；具体实施范围与验收继续遵循当前任务和项目约定。
